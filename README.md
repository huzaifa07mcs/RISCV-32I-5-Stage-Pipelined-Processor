# RV32I 5-Stage Pipelined Processor

A 32-bit single-core RISC-V (RV32I) pipelined processor written in Verilog.

## Features

- RV32I ISA (selected instructions)
- 5-stage pipeline
- Hazard Detection Unit
- Forwarding Unit
- Load-use Stall Logic
- Branch Flush
- Self-checking Testbenches

## Tools

- Verilog
- Xilinx Vivado
- Git
